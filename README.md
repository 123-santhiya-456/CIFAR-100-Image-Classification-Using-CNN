# CIFAR-100 Image Classification Using Convolutional Neural Network (CNN)

## 📌 Project Overview
This project implements a **Convolutional Neural Network (CNN)** to classify images from the **CIFAR-100 dataset**.  
CIFAR-100 consists of small RGB images belonging to **100 different classes**, making it a challenging and realistic dataset for deep learning image classification.

The project demonstrates how CNNs outperform traditional neural networks by effectively capturing spatial features from images.

---

## 🧠 Dataset
- **Dataset Name:** CIFAR-100
- **Image Size:** 32 × 32 (RGB)
- **Number of Classes:** 100
- **Total Images:** 60,000  
  - Training Images: 50,000  
  - Testing Images: 10,000

---

## 🛠️ Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Jupyter Notebook

---

## 🔍 Project Workflow
1. Load CIFAR-100 dataset
2. Normalize image pixel values
3. Visualize sample images and labels
4. Build CNN architecture
5. Train the model on training data
6. Evaluate performance on test data
7. Visualize predictions and accuracy

---

## 🏗️ CNN Model Architecture
- Convolutional Layers (ReLU activation)
- Max Pooling Layers
- Dropout for regularization
- Flatten Layer
- Fully Connected Dense Layers
- Output Layer with Softmax activation (100 classes)

---

## 📊 Results
- CNN achieved significantly better performance than a basic neural network
- Improved feature extraction using convolutional layers
- Model evaluated using accuracy on test dataset
